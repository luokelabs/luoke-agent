    设计说明

    少打扰（11-03）

    不打断你手上的事：入口不靠一直摆在眼前，提醒只在该出现的地方出现一次。

    • 侧栏能收起：窗口左上角的按钮或 ⌃⌘S，最小收成一列图标（今天、活动、应用、设置；展开的应用也只剩图标），悬停看名字；底部只留状态灯，点了照样进「设置 · 模型」。收起还是展开记在这台 Mac 上。
    • 完整入口在顶部菜单：螺壳在前台时，「前往」列出今天、活动、搜索或问螺壳、每个装好的应用、添加应用、权限、模型；「螺壳」里有设置（⌘,），「显示」里收起侧栏。菜单只放入口，不写计数和状态。
    • 菜单栏图标只放必要的：状态、急事（只列「当场说」的那几类，处理完就没了）、打开螺壳、暂停提醒、退出。平时不带数字，有急事才多一个小点。不列应用、活动、设置。
    • 通知只给急事：默认只有可疑邮件、安全问题当场说；其余放进简报或只放在窗口里。简报默认每天早上一次（原来每小时）。Dock 图标不带数字。
    • 状态放在它自己的地方：有新版本在「今天 · 顺便看看」，记忆想问的在「要你决定」，等你允许的权限在「今天」的卡片和「设置 · 权限」。侧栏和菜单都不亮灯。
    • 模型名：侧栏底部写着现在用的模型，点了进「设置 · 模型」换档；换档在空闲时下载，下完再换。

    少常驻入口（11-02）

    侧栏只放每天都要来的地方。应用不常驻，等到要你决定时，跟着那件事出来。

    10-27 稿现在（11-02、11-03）

    顶部菜单只有系统默认的几项螺壳在前台时，「前往」放完整入口：今天、活动、搜索或问螺壳、每个装好的应用、添加应用、权限、模型
    菜单栏图标状态、今天、问螺壳、暂停提醒、应用有新版本、设置状态、急事、打开螺壳、暂停提醒、退出。平时不带数字，有急事才多一个点
    权限侧栏单独一项，带计数用到时在「今天」出一张卡片（needs-access）；搜索里照片没允许，就在搜索结果里问；全部列表在「设置 · 权限」
    有新版本侧栏应用旁亮红点「今天 · 顺便看看」里一行，主控出的，点「升级」交给主控
    螺壳搜索侧栏一项、自己一页没有自己的页：搜索在底部输入条（⌘K），结果页给所有来源用
    进应用的页从侧栏点从卡片、搜索结果、问螺壳回答上的应用图标和按钮点进；展开「应用」也能进
    • 侧栏少、顶部菜单全：窗口侧栏只放常去的四项，最小收成一列图标；螺壳在前台时，顶部菜单「前往」列出全部入口，想直接去某个应用、权限或模型，一步就到。两处的应用列表都来自装好的应用，由主控画。
    • 应用在哪出现：「今天」的卡片、搜索结果的每一条、问螺壳的回答、权限请求。每处都带应用的图标，点了进它的基础页；会改动东西的按钮照旧要你点。
    • 主控自己的卡片：有新版本、装好了、首次设置的下一步，由主控放进「今天」，按钮交回主控、不经 agent（agent 不调安装接口）。
    • 「应用」收起还是展开记在这台 Mac 上；正在看某个应用的页时，收起的那一行亮着、写着是哪个应用。

    分工：谁定、谁画

    用户只看到一个螺壳、一个窗口；后面主控和 agent 仍是两个组件、两个进程，分工照顶层 ADR 0014（10-27 修订）。设计上的决定大家一起定（11-02 起）。

    界面的哪一块谁定谁画
    外框、侧栏、页面布局主控主控
    「应用」一行和展开的列表、「添加应用」；装、升级、换回、卸载；首次设置主控主控
    顶部菜单（完整入口）主控主控
    菜单栏图标（状态、急事）哪件算急事由 agent 说，照「设置 · 提醒」里「当场说」的那几类主控
    「今天」里主控自己的卡片（有新版本、装好了）主控主控
    搜索结果页（HitsList）各工具回结果（service.ask.search），agent 汇总主控
    「今天」：出哪些事、什么顺序、什么时候出agent主控
    卡片工具写内容（A2UI，放 outbox），agent 校验、挑时机主控
    工具的基础页工具写（资源 page/<id>）主控
    深界面（扫描的文件夹树、规则编辑）工具工具自己的 .app
    邮件助手、记忆现有的网页各自过渡期由主控用网页视图套进窗口
    窗口和 agent 之间的接口主控和 agent 一起，beta 2 之前定—
    • 要一起定的接口：主控怎么读「今天」、卡片和基础页，点按怎么交回 agent；通知以谁的名义发；agent 进程由谁拉起；侧栏「今天」的计数、「应用」各行的计数（工具报概览、agent 读，主控向 agent 要）；菜单栏图标现在有没有急事（agent 说）。
    • 样子统一：卡片和基础页由渲染器（luoke-agent 的 LuokeA2UI）画，工具只描述放什么。
    • 关掉「主动提醒」：agent 不再主动发简报和通知；窗口、「今天」、基础页和装应用的入口照旧在。

    搜索和问螺壳：同一条输入条，不用抽屉

    beta 2 上（luoke-agent.chat 要先交评测集、过发布评测，ADR 0017）。抽屉是把对话当成窗口的一部分，常年占掉三分之一的宽度，打开它就得在两块之间来回看。换成「就地问」：

    • 搜索和问螺壳合成一条：打字就出搜索结果，不经模型，各来源先回先画；回车再让螺壳回答。回答里引用的结果带「打开」，点了才开。「搜索结果」进整页，按来源分段、能筛选。
    • 底部一条浮动输入条，⌘K 或直接开始打字就叫出；它带着上下文标签（你在哪一页、选中了哪一行），可以点掉。
    • 回答浮在当前页上，半透明、不遮整屏；还是卡片，会改动东西的照样要你点。Esc 收起。
    • 一问一答就够的不留痕迹；想留着的「钉到今天」，想接着聊的「展开」成整页对话（对话记录在「活动」里能找回）。
    • 列表里每一行悬停时有「问」，点了就带着这一行去问，不用再描述「那个文件夹」。
    • ⌥Space 在任何窗口里都能叫出同一个面板：在工具自己的窗口里，工具把当前选中的东西递给 agent（service.ui.context，beta 2 之前和邮件助手定格式；递过来的照旧当数据，不当指令）。

    工具怎么登记

    在配件清单的 capabilities 里加三块，只加不改，不升协议版本：没有这三块的工具照样只出卡片。内容在运行时向工具要，和 outbox 一样走它自己的 socket。主控原样保存，不用改代码。

    // luoke-scan 的配件清单（节选）
"capabilities": {
  "protocol": 1,
  "socket": "~/.luoke-scan/run/agent.sock",
  "reports": [ …已有… ],
  "actions": [ …已有… ],

  "service": {
    "summary": true,
    "pages": [
      {"id": "overview", "title": "概览"},
      {"id": "cleaned",  "title": "清理记录"}
    ],
    "ui": {
      "open": "scan_open",
      "pages": [
        {"id": "details", "title": "全部明细"},
        {"id": "rules",   "title": "规则"}
      ]
    }
  },
  "permissions": [ …见下一节… ],
  "listing": {
    "tagline": "找出吃空间的和可疑的，替你清掉不会丢东西的",
    "category": "系统"
  }
}
    登记的出现在哪
    reports今天（按急不急分区）、通知和简报、设置 · 提醒
    outbox · auto-done今天 ·「已经替你做了」、活动；撤销 / 放回
    actions卡片和页面上的按钮（只在你点了以后调用）；「添加应用」详情里「会代你做的事」
    service.summary资源 summary：{"count", "text"}。应用页的概览、「应用」展开后每行的计数；不弹通知，不进简报
    service.asksearch：搜索结果页和输入条下的结果；suggest：问螺壳打开时的推荐（工具协议 §1b）
    service.pages资源 page/<id>：一组 A2UI 消息，和卡片一样校验（200 个组件、2000 字）。应用页里的基础页
    service.ui深页只写页 id；open 是工具的只读动作（{"page"}），由工具自己打开。「打开完整界面」和各深页入口；手机上灰掉，写「在 Mac 上」
    permissions「添加应用」的详情、「设置 · 权限」、「今天」里的权限卡片和申请弹窗
    listing发布流水线抄进发布清单，「添加应用」读发布清单；大小由流水线实测，档位由配方和评测定
    • 不用自定义 URL scheme 跳到工具的界面：别的程序能注册同名 scheme。深页由工具的只读动作打开，或由螺壳按 bundle id 和签名找到它。
    • 资源地址只在协议里当标识，不交给系统打开。outbox 照旧 luoke://<工具>/outbox；新资源用相对 id（summary、permissions、page/<id>），完整地址由 luoke-agent 和 luoke-core 定。

    应用：装和升级

    不叫「市场」：这里的都是螺壳挑好、签过名的，不是谁都能上架。侧栏只有一行「应用」，点开列出装好的，最后一行「添加应用」打开全部。有新版本不在侧栏亮灯，在「今天 · 顺便看看」出一行。这几页是主控画的，每一步要你点；agent 不调安装、卸载的接口。

    • 列什么：发布清单里的全部应用（现在：邮件助手、输入法、螺壳扫描、螺壳搜索；记忆随螺壳装）。档位不够的照样列出、写明要哪一档。
    • 装之前：详情页写清它会告诉你哪几类事、会代你做哪些事、要哪些权限、占多大。介绍和权限说明来自发布清单，大小来自流水线实测。
    • 装的时候：下载、核对签名、装好、本机试跑，进度就在详情页里走；关掉窗口也照装，装好在「今天」说一声。验签名、Gatekeeper、回退、档位限制都在主控。
    • 装好之后：它的第一步（连邮箱、允许输入监控……）由工具在 outbox 报出来，成为「今天」里的一张卡片，不另开向导窗口。
    • 升级、换回上一版、卸载在详情页和「更多」里，就是主控现在「应用」窗口的那些操作，挪成窗口里的一页。首次设置照旧归主控。
    • 以后有别人做的应用：先只上螺壳签名过的；第三方要过审核、签名、评测才能列进来（到时另定）。

    已经定的

    1. 一个窗口，主控画，agent 供内容（ADR 0014 的 10-27 修订）；菜单栏和以后的手机上是同一套卡片和页面。
    2. 深界面归工具：工具可以有自己的界面，不设限；基础信息和常用操作做成基础页放进窗口。
    3. 不用抽屉：就地问；搜索和问螺壳是同一条输入条，都在 beta 2。
    4. 已有的网页：邮件助手和记忆的网页，过渡期套进同一个窗口，再逐页改。
    5. 装和升级在窗口里，归主控，叫「应用」，不叫市场。
    6. 用词：界面上叫「应用」；协议和文档里叫「工具」；「服务」不用。体检改名「螺壳扫描」（11-03，仓库和配件 id 是 luoke-scan）。
    7. 少常驻入口（11-02）：侧栏只有今天、活动、应用（一行，默认收起）、设置；权限并进设置；应用的入口出现在要你决定的地方。
    8. 少打扰（11-03）：侧栏最小收成一列图标；完整入口在螺壳的顶部菜单「前往」里；菜单栏图标只放状态和急事，平时不带数字；通知只给急事，简报默认每天早上一次；侧栏底部的模型名点了进「设置 · 模型」。
    9. 手机不在 beta 2。
    10. 时间：契约字段随时进 main；窗口合并、搜索、问螺壳都在 beta 2（以 agent 当螺壳主界面上线为准）。
