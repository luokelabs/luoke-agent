# 螺壳主窗口（第一版，2026-11-03 定）

beta 2 以 agent 当螺壳的主界面上线为准。这里写主窗口第一版定下来的样子；螺壳.app 和 agent 核心之间的接口见 [界面接口.md](界面接口.md)（草案）。

- 原型：[主窗口原型.html](主窗口原型.html)，用浏览器打开就能点。地址后面加 `#today,selftest` 会跑一遍自带的检查，结果写在页面最后；`#today,collapsed` 打开时侧栏是收起的。
- 在线版（和这份同一个版本）：<https://claude.ai/artifact/WgFWujPhN2eSx9Qa5HiY19>
- 卡片、基础页、工具和权限怎么登记，见 [工具协议.md](工具协议.md) §1a；这里不重复。

## 原则：少打扰

不打断用户手上的事。入口不靠一直摆在眼前，提醒只在该出现的地方出现一次。

- 常驻的入口越少越好；应用的入口跟着要用户决定的那件事出来（「今天」的卡片、搜索结果、问螺壳的回答、权限请求）。
- 状态放在它自己的地方，不在侧栏、菜单上亮灯或写计数。
- 系统通知只给急事。

## 窗口

**侧栏**：今天、活动、应用、设置四行。

- 「应用」默认收起成一行，点开列出装好的应用和「添加应用」。收起时叠着装好的应用的小图标；正在看某个应用的页，这一行亮着，小图标里那个应用的亮着、别的淡下去（在「添加应用」时只是这一行亮着）。展开还是收起记在这台 Mac 上。
- 侧栏能收起，最小是一列图标（72 pt）：今天、活动、应用、设置，展开的应用也只剩图标，悬停看名字。不整个藏掉。左上角的按钮、⌃⌘S、「显示」菜单都能切换，记在这台 Mac 上。
- 底部是主控的状态灯和现在用的模型名，点了进「设置 · 模型」换档；收成图标时只留状态灯，点了一样。
- 「今天」的计数是灰字；有新版本不在侧栏亮灯。

**今天**：一栏，最宽 700 pt。标题旁边是日期，右边是「一件件处理 n」（没有要你决定的时灰掉）。从上到下：

- 简报（点了简报的通知才出，见下）；
- 急事横幅（可疑邮件这类），浅红底、没有边；
- 已经替你做了：每件一行（做了什么、几点、撤销或放回），最多三行，多的点「还有 n 件」就地展开；接上核心时点这一行展开成工具写的那张卡片；
- 要你决定：卡片；空了画吉祥物和一句「今天没什么要你操心的。」。要权限时，在这里出一张卡片（`needs-access`）；
- 顺便看看：有新版本、订阅精选这类不急的。

**简报**：通知里是核心照模板拼的一句（「还有 3 件等你：A、B、C；急事：X；替你做了 2 件。」，不经模型）。点了通知，「今天」最上面出一段话，由窗口照「今天」现有的拼：替你做了的几件、急事的标题（红字）、要你决定的几件。要你决定的那几个词能点，点了滚到那张卡片、卡片外面亮一圈；答了的划掉。「收起」收起。

**一件件处理**：点「一件件处理」，第一张卡片长成一块面板，盖住「今天」，一次只摆一件。顶上一条：标题、每件一格的进度、还有几件、「完成 Esc」。下面是哪个应用、标题（26）、正文（15）、几行明细、36 pt 的按钮和「跳过」、按键提示。⏎ 答标了 primary 的那个按钮（没标的不答），↓ 跳过，Esc 回「今天」；这张卡片还在处理上一下点按时，按钮灰掉，⏎ 也不算。都答了：吉祥物、「今天没什么要你操心的」、「回到今天」；跳过了的：「还有 n 件留着」。

**紧凑**（设置 · 显示）：「今天」画成一张表。顶上一条写几件急事、要你决定、做了，和「一件件处理」；按段分组（急事、要你决定、已经替你做了、顺便看看），每行是图标（16）、应用、事情（后面一行小字）、时间、操作（最多两个小按钮，卡片处理一次点按时灰掉）。卡片里有要填、要选的（选项、输入框、日期、滑条、勾选），这一行不给按钮，给「展开」，在下面画整张卡片。打开网页的按钮，网站写在按钮后面；没写网站的不列。

**活动**：时间线。时间在左、右对齐；一条竖线上的点，急事红、刚做的用强调色；应用图标、做了什么、撤销或放回。按今天、昨天分组。beta 2 不画这一页。

**应用的页**：每个应用一页，上面是工具出的基础页（`service.pages`，A2UI），「打开完整界面」和深页由工具自己的窗口打开（`service.ui`）。有新版本时在页上能升级。

**添加应用**：列出螺壳挑好、签过名的全部应用，装之前看得到会做什么、要什么权限、占多大。装、升级、换回、卸载归主控。

**设置**：五个标签。

| 标签 | 放什么 |
|---|---|
| 提醒 | 主动提醒总开关；简报（默认每天早上，能选早晚各一次、只在我打开时）和通知里那一句的样子；免打扰（默认 22:00–08:00）；每类事怎么说（当场说、放进简报、只放在窗口里、不要） |
| 显示 | 「今天」的密度：标准（卡片）或紧凑（一张表），带小样；只记在这台 Mac 的这个窗口里 |
| 权限 | 系统权限（列在螺壳或应用名下，写明谁在用）、账号、代你做的事、每次都问的事 |
| 模型 | 档位和模型、引擎状态、能耗、用电池时也在后台跑 |
| 隐私 | 数据只在这台 Mac 上、记忆、诊断信息、卸载螺壳 |

**搜索和问螺壳**：同一条输入条，在窗口底部，⌘K 或直接打字叫出。

- 打字就出搜索结果，不经模型，各来源先回先画；「搜索结果」进整页，按来源分段、能筛。
- 回车让螺壳回答。回答浮在当前页上，带上下文标签（在哪一页、选中了哪一行），Esc 收起；会改动东西的按钮照样要点。
- 一问一答不留痕迹；想留的「钉到今天」，想接着聊的「展开」成整页对话（记录在「活动」里）。
- ⌥Space 在任何窗口里叫出同一个面板；在工具自己的窗口里，工具把选中的东西递过来（`service.ui.context`，当数据）。

## 顶部菜单：完整入口

螺壳在前台时，屏幕顶部的菜单就是完整入口；侧栏收起来也一步就到。菜单只放入口，不写计数和状态。

| 菜单 | 项 |
|---|---|
| 螺壳 | 关于螺壳；设置…（⌘,）；检查更新…；隐藏、隐藏其他、全部显示；退出螺壳（⌘Q） |
| 编辑 | 系统标准的几项 |
| 显示 | 收起侧栏 / 展开侧栏（⌃⌘S）；进入全屏幕 |
| 前往 | 今天（⌘1）、活动（⌘2）、搜索或问螺壳（⌘K）；应用：每个装好的应用、添加应用…；权限、模型 |
| 窗口 | 系统标准的几项 |
| 帮助 | 螺壳使用说明 |

「前往」里的应用列表和侧栏的一样，来自装好的应用。

## 菜单栏图标：只放必要的

别的程序在前台时，螺壳只在菜单栏留一个图标。

- 平时不带数字；有急事（「当场说」的那几类）没处理时多一个小点，处理完就没了。
- 点开只有：状态（就绪；暂停时写到几点）、急事（有才列）、打开螺壳、暂停提醒一小时、退出螺壳。
- 不列应用、活动、设置；要去这些地方，打开螺壳用侧栏或顶部菜单。

## 提醒

- 每类事四档：当场说、放进简报、只放在窗口里、不要。默认只有可疑邮件、安全问题当场说。
- 系统通知只给当场说的。简报默认每天早上一份（原来攒满一小时，见 [DESIGN.md](../DESIGN.md) §5）。
- Dock 图标不带数字。
- 有新版本在「今天 · 顺便看看」，记忆想问的在「要你决定」，等你允许的权限在「今天」的卡片和「设置 · 权限」。
- 关掉「主动提醒」：agent 不再主动发简报和通知；窗口、「今天」、基础页照旧在。

## 谁定、谁画

用户只看到一个螺壳、一个窗口；后面主控和 agent 仍是两个组件（顶层 ADR 0014 的 10-27 修订）。

| 界面的哪一块 | 谁定 | 谁画 |
|---|---|---|
| 外框、侧栏、页面布局 | 主控 | 主控 |
| 「应用」一行和展开的列表、「添加应用」；装、升级、换回、卸载；首次设置 | 主控 | 主控 |
| 顶部菜单（完整入口） | 主控 | 主控 |
| 菜单栏图标（状态、急事） | 哪件算急事由 agent 说，照「设置 · 提醒」里当场说的那几类 | 主控 |
| 「今天」里主控自己的行（有新版本、装好了） | 主控 | 主控 |
| 搜索结果页 | 各工具回结果（`service.ask.search`），agent 汇总 | 主控 |
| 「今天」：出哪些事、什么顺序、什么时候出 | agent | 主控 |
| 卡片 | 工具写内容（A2UI，放 outbox），agent 校验、挑时机 | 主控 |
| 工具的基础页 | 工具写（`page/<id>`） | 主控 |
| 深界面（扫描的文件夹树、规则编辑） | 工具 | 工具自己的 .app |
| 邮件助手、记忆现有的网页 | 各自 | 过渡期由主控用网页视图套进窗口 |

卡片和基础页由同一个渲染器（本仓库的 `LuokeA2UI`）画。

## 接口

见 [界面接口.md](界面接口.md)（草案）。

- 「今天」和卡片走 `/feed`，点按交回 `/action`。
- 「今天」的计数、菜单栏图标的小点，都从 `/feed` 的 `cards` 算。
- 通知由 agent 定发不发，螺壳.app 以「螺壳」的名义发。
- 核心由螺壳.app 拉起。
- 用户在不在、窗口开没开，照旧报 `/presence`、`/window`。

## 样子和动效

- 颜色在 `Theme.swift`。字号只用 26、15、14、13、12，字重只用常规、中等、半粗；间距在 4 pt 的格子上；圆角 6、8、14、20（「一件件处理」的面板 16）。
- 卡片：浅色是白底加一层很淡的影子（`0 1 2` 6 %、`0 4 12 -6` 10 %，#3A1F14），没有边；深色是 1 px 的边（白的 6 %），没有影子。
- 按钮四级：实心的主按钮、浅底的次按钮（字色的 6 %，没有边）、只有字的、红的。行里的「撤销」「放回」是红字的字按钮。
- 侧栏选中是字色的 7 % 的底，没有影子。
- 动效（`Motion.swift`）。曲线：进场 `(0.23,1,0.32,1)`、移动 `(0.77,0,0.175,1)`、抽屉 `(0.32,0.72,0,1)`、退场 `(0.3,0,0.8,0.15)`。

| 动作 | 怎么动 |
|---|---|
| 按下按钮 | 90 ms 缩到 0.97 |
| 答完一件 | 卡片 130 ms 淡出、缩到 0.97；别的 320 ms 补位（进场，晚 50 ms）；应用图标 440 ms 飞进「已经替你做了」新的那一行，往左边空白处偏约 36 pt 再落回，路上从 28 缩到 20；那一行的字在图标落地时（约 280 ms）出现，每段 220 ms，错开 30 ms；计数在落地时滚一格 |
| 撤销 | 图标沿原路飞回；还在路上就从当时的位置倒回去 |
| 进「一件件处理」 | 第一张卡片 420 ms 长成面板（抽屉）；「今天」150 ms 淡出（退场）；面板里的各块从 100 ms 起错开 35 ms |
| 下一件 | 旧的 160 ms 往上走 12 pt；新的 70 ms 起 300 ms 从下面 16 pt 来；进度那一格 260 ms 填满；键盘上按的只淡入淡出 120 ms |
| 换页 | 侧栏选中的底 280 ms 滑过去（移动）；旧页 130 ms 淡出（退场）；新页各块 260 ms 升 8 pt，错开 30 ms；「活动」的竖线 420 ms 从上往下画出来 |
| 点开简报 | 下面的内容 340 ms 让位；那段话 170 ms 起 420 ms 升 10 pt |
| 密度的分段 | 240 ms 滑过去 |

减少动态效果时只淡入淡出，不超过 150 ms，按钮按下不缩。

## 实现（`window/`）

Swift 包 `LuokeWindow`（macOS 14 起），螺壳.app 引它；卡片和基础页用同仓库的 `LuokeA2UI` 画。

- `MainWindowView(model:)`：整个窗口；`LuokeCommands`：顶部菜单（换掉「显示」里的侧栏一项，加「前往」）；`StatusMenuContent`：菜单栏图标的菜单。三处都从 `WindowModel` 读，顶部菜单和菜单栏图标的项来自同一份描述（`topMenus`、`statusMenu`）。
- 接 agent 核心：`AgentConnection(socketPath:model:)` 订阅 `agent.sock` 的 `/feed`，「今天」的四段、菜单栏图标的急事、「设置 · 提醒」用核心的（`AgentFeed` 把事件填进 `WindowModel`）；点按和改设置经 `WindowBackend` 交回 `/action`、`/settings`。螺壳.app 报窗口和在不在用 `reportWindow`、`reportPresence`，系统通知照 `feed.onNotify` 发。不接时（截图、测试、`luoke-window-demo` 不带 `--agent`）用示例数据（`Sample`，和原型一样）。「接上核心」的截图和测试里，螺壳扫描那部分是它的场景样例经真核心得来的（`ToolSample`，`Resources/samples/`，由 `scripts/window_samples.py` 生成，见工具协议 §11），邮件助手、记忆的还是手写的。
- 应用的页（接口 §6）：接上核心时照 `GET /apps` 画：运行状态和概览一句话、页的标签（`pages` 在窗口里画，`ui.pages` 带外链箭头）、缺的权限（`needs`，点了进「设置 · 权限」）；每一页是工具的 A2UI，打开、换标签、`apps` 事件、页上点完按钮时重新取，按钮照卡片走 `/action`。「打开完整界面」只在工具有自己的界面（`ui`）时出，点了调 `POST /open`。核心没连着的应用（例如记忆）照旧。
- 「设置 · 权限」（§10）：打开时取 `GET /permissions`；在螺壳名下的（`owner: "luoke"`）同一项合成一行，写哪些应用在用。按钮只照每行的 `can` 出（`settings`「打开系统设置」、`request`「允许」→ 先出说明、点「继续」才交、`on`/`off` 是开关、`open`「打开」、`remove`「移除」），点了才调 `POST /permissions`，答的那句话画成底部的提示；每次都问的只列出来。在螺壳名下的系统权限接着本体时点了调 `WindowHost.askPermission`，下面每个应用一行「允许」的开关（§10）。
- 螺壳自己的权限：螺壳.app 自己查（例如完全磁盘访问），启动时和变了时调 `WindowModel.reportHostPermissions(["fda": .granted])`（或 `AgentConnection.reportHost(permissions:)`），转成 `POST /host`；值是 `.granted`、`.denied`、`.ask`，`nil` 是不再报这一项。连接记着报过的，核心重启、重新连上时再报一遍。窗口不查系统的授权。
- 窗口里的按钮、开关、分段、下拉框都自己画（样子照原型，颜色在 `Theme.swift`）；`LuokeA2UI` 加了可选的样式接口（`a2uiButtonStyle`、`a2uiDrawn`、`a2uiCardChrome`、`a2uiFont`），窗口把卡片画成同一个样子，不设的宿主照旧是系统样式。
- 简报：点了核心发的通知，本体调 `model.openNotification(userInfo)`：编号是 `brief` 的回「今天」并把简报放在最上面（`openBrief()`），别的回「今天」。`收起` 是 `closeBrief()`。
- 一件件处理：`enterFocus()`、`skipFocus(viaKey:)`、`answerFocus(_:viaKey:)`、`answerFocusPrimary()`、`exitFocus()`；答了的就是从「要你决定」里走掉的。
- 密度：`setDensity(.compact)`，记在 `UserDefaults`（`luoke.window.density`）。
- 截图：`Snapshot.screens()` 列出全部界面（53 个，各有浅色、深色）。默认照螺壳.app 现在发的样子画：beta 2 精简版（`.beta2`：今天、应用页、设置，底部只有搜索）、接上核心、侧栏「应用」展开；邮件助手和螺壳扫描的卡片、页、权限都是它们录的场景样例经真核心得来的（`ToolSample`，默认邮件 `morning`、扫描 `full-report`：一张很长的一轮卡片），不手写。另有：`-whole` 是整页（窗口拉高，往下滚才看得到的也画出来）；`stress-` 是压力场景（录的卡片复制几份、什么都没有、还在等、页面拿不到、最小和大窗口）；`full-` 是完整版里 beta 2 还没有的页（活动、问螺壳、对话、记忆……），用手写的 `Sample`。`luoke-window-shots <目录>` 画成 PNG。离屏画、不开窗口，没有图形会话也能跑。每个 PR 由 GitHub Actions 截一遍，贴在 PR 的评论里，和 main 比变了哪些界面。
- 接螺壳.app（本体，luoke-core#68）：本体实现 `WindowHost`，设到 `WindowModel.host`。模型、隐私、添加应用、升级交给它，打开本体现有的窗口。菜单栏用本体的菜单，`StatusMenuItems.items(model:openWindow:)` 给急事、打开螺壳、暂停提醒那几项现成的 `NSMenuItem`。系统设置由窗口打开（`AgentConnection.settingsOpener`）。beta 2 只画今天、应用页、「设置 · 提醒」「设置 · 权限」：本体设 `model.features = .beta2`。见 [界面接口.md](界面接口.md) §14。
- 演示：`swift run --package-path window luoke-window-demo` 用示例数据开一个窗口（要在有图形界面的 Mac 上）。
- 测试：`swift test --package-path window`。界面行为照原型的自查一条条对过来（侧栏、图标列、「应用」一行、卡片点按和撤销、一件件处理、简报、密度、权限、问螺壳、设置、顶部菜单、菜单栏图标），样子和动效的值有自己的测试（`ThemeTests`）；截图测试检查每个界面都画得出、不是空白、没有画不出的系统控件，同一个界面画两次一样。

## 用词

- 界面上叫「应用」，协议和文档里叫「工具」，不说「市场」「服务」。
- 体检改名「螺壳扫描」（11-03，配件 id `luoke-scan`）。
