# 螺壳主窗口（第一版，2026-11-03 定）

beta 2 以 agent 当螺壳的主界面上线为准。这里写主窗口第一版定下来的样子；螺壳.app 和 agent 核心之间的接口见 [界面接口.md](界面接口.md)（草案）。

- 原型：[主窗口原型.html](主窗口原型.html)，用浏览器打开就能点。地址后面加 `#today,selftest` 会跑一遍自带的检查，结果写在页面最后；`#today,collapsed` 打开时侧栏是收起的。
- 在线版（和这份同一个版本）：<https://claude.ai/artifact/WgFWujPhN2eSx9Qa5HiY19>
- 卡片、基础页、工具和权限怎么登记，见 [工具协议.md](工具协议.md) §1a；这里不重复。

## 原则：少打扰

不打断用户手上的事。入口不靠一直摆在眼前，提醒只在该出现的地方出现一次。

- 常驻的入口越少越好；应用的入口跟着要用户决定的那件事出来（「今天」的卡片、搜索结果、问螺壳的回答、权限请求）。
- 状态放在它自己的地方，不在侧栏、菜单上亮灯或写计数。
- 系统通知只给急事。

## 窗口

**侧栏**：今天、活动、应用、设置四行。

- 「应用」默认收起成一行，点开列出装好的应用和「添加应用」。收起时叠着装好的应用的小图标；正在看某个应用的页，这一行亮着，小图标里那个应用的亮着、别的淡下去（在「添加应用」时只是这一行亮着）。展开还是收起记在这台 Mac 上。
- 侧栏能收起，最小是一列图标（72 pt）：今天、活动、应用、设置，展开的应用也只剩图标，悬停看名字。不整个藏掉。左上角的按钮、⌃⌘S、「显示」菜单都能切换，记在这台 Mac 上。
- 底部是主控的状态灯和现在用的模型名，点了进「设置 · 模型」换档；收成图标时只留状态灯，点了一样。
- 「今天」一行同一时间只有一个标记：有急事只画红点，没急事才画灰字的数，只数要你决定的（和「一件件处理」同一个数）。侧栏收成图标时，红点、数字都在图标右上角。有新版本不在侧栏亮灯。

**宽窗口**：按内容区（窗口减去侧栏）的宽分三档，各页一样。宽了一栏不变宽，多出来的地方放第二栏，再宽就留白。

| 档 | 内容区 | 怎么排 |
|---|---|---|
| 窄 | 不到 760 pt（最小的窗口 860 宽、侧栏展开时） | 一栏，两边边距从 44 收到 24 |
| 一栏 | 760–1199 pt | 一栏，最宽 700 pt（连边距），居中 |
| 宽 | 1200 pt 起（1440 宽的窗口起） | 页上有放进侧栏的东西时：标题横跨，下面主栏（和一栏时一样宽）+ 侧栏 380 pt，中间空 32，一组最宽 1112 pt、居中，再宽也不长；侧栏没东西时照一栏画 |

- 「今天」（标准）：侧栏只放已经替你做了（先列 6 行），别的（连不上螺壳、核心的几句、简报、急事、要你决定、顺便看看）在主栏。紧凑的表、一件件处理不分栏；表最宽 1080 pt、居中。
- 应用页（接上核心的）：主栏是缺的权限、标签、工具的页；侧栏是工具在页上写了 `"placement": "aside"` 的段（工具协议 §4），第一页还有「这个应用」。工具没写的，页照原来的顺序画在主栏。
- 应用页分段（工具协议 §4 pageSections，页的根写了 `"layout": "sections"`）：不再整页一张卡片。页头那一行（标题、「上次查 …」、主按钮）不画卡片；一排数每格一张小卡片（格和格之间空 10）；一段一张卡片，段的小标题（图标、字、数）画在卡片外面上方，和上一张隔 18，别的隔 12。分两栏时侧栏的段也各一张卡片。
- 底部的搜索框和主栏同宽、在主栏的中线上；有侧栏时跟着主栏往左挪。
- 搜索结果（2026-11-10）：工具给了 `hits` 的，按类型分组画（工具协议 §1b、界面接口 §7）。顶上一排按类型的筛选和条数；PDF、表格、图片画成缩略图格子，一行四个，名字下面写最后一两层文件夹，角上标页或工作表，每组先列四个，再「还有 N 个 ›」；邮件按收件的邮箱分块，一封一行。列表里不画摘要和按钮，不画黄色高亮；选中（点、↓）后一行变三个，右边出预览，有「打开」「在访达中显示」。回车打开，⌘↩ 在访达中显示。只给卡片的工具照旧画卡片，放在后面。截图 `search-hits*`，数据是编的（`SearchSample`）。
- 设置、添加应用还是一栏。

**今天**：一栏，最宽 700 pt（宽窗口见上）。标题旁边是日期，右边是「一件件处理 n」（没有要你决定的时灰掉）。从上到下：

- 简报（点了简报的通知才出，见下）；
- 急事（可疑邮件这类）：段标题「急事 n」，和「要你决定 n」一样数件数（一叠里几件算几件）；卡片和别的卡片一样白底，应用图标右下角一个红色角标；只有工具写成 `destructive` 的按钮（「移到垃圾邮件」）是浅红底红字；
- 已经替你做了：每件一行（做了什么、几点、撤销或放回），最多三行，多的点「还有 n 件」就地展开；接上核心时点这一行展开成工具写的那张卡片。工具给了分组的（工具协议 §4 `doneGroup`），同一组合成一行：「可疑邮件 · 已移到垃圾邮件 4 封」加邮箱标签，点一次撤销把这一行里的每一件都撤销；
- 要你决定：卡片，同一个应用同一类的挨着（照这一类第一张出现的位置），3 张以上叠成一叠。有两类以上时，段标题下面一行「按类处理」：不止一件的那几类每类一块（应用图标、类名、件数），点了进「一件件处理」只走这一类；类名是应用清单 `reports` 里的名字（和「设置 · 提醒 · 每类事」同一个），核心给不出时写应用的名字。只有一类、或每类都只有一件时不画这一行。空了的时候，整页只剩这一段才画吉祥物和一句「今天没什么要你操心的。」（核心的数据还没到时写在准备）；页上还有急事、做了的、顺便看看时整段不画，免得那句话和上面的急事打架。要权限时，在这里出一张卡片（`needs-access`，不管工具报得急不急）；
- 顺便看看：有新版本、订阅精选这类不急的。

**简报**：通知里是核心照模板拼的一句（「还有 3 件等你：A、B、C；急事：X；替你做了 2 件。」，不经模型）。点了通知，「今天」最上面出一段话，由窗口照「今天」现有的拼：替你做了的几件、急事的标题（红字）、要你决定的几件。要你决定的先列 3 件（标题一样的只列一次），再多的写「等」（「还有 40 件等你：A、B、C 等」），点「等」滚到「要你决定」；那几个词能点，点了滚到那张卡片、卡片外面亮一圈；答了的划掉。整段最多两行，放不下就由细到粗换写法（替你做了的只写件数、要你决定的少列几件、急事只写件数）。「收起」收起。

**一件件处理**：次序和「今天」页上一样，一类处理完再下一类。点「一件件处理」，第一张卡片长成一块面板，盖住「今天」，一次只摆一件。顶上一条：标题、每件一格的进度（超过 12 件时是一整条加「3 / 40」）、还有几件、「完成 Esc」。下面是哪个应用、标题（26）、正文（15）、说明（13）、几行明细、36 pt 的按钮和「跳过」、按键提示；这一件放不下时中间滚动，按钮和按键提示留在底部。⏎ 答标了 primary 的那个按钮（没标的不答），↓ 跳过，Esc 回「今天」；这张卡片还在处理上一下点按时，按钮灰掉，⏎ 也不算。都答了：吉祥物、「今天没什么要你操心的」、「回到今天」；跳过了的：「还有 n 件留着」。从「按类处理」进来的只走那一类：顶上写「一件件处理 · 类名」，这一类都答了而「要你决定」里还有别的事时，写「「类名」都处理完了」和还剩几件、「回到今天」。

**紧凑**（设置 · 显示）：「今天」画成一张表。顶上一条写几件急事、要你决定、做了，和「一件件处理」；按段分组（急事、要你决定、已经替你做了、顺便看看），每行是图标（16）、应用、事情（后面一行小字：工具写的副标题，工具协议 §4 `subtitle`，没写就是卡片里的说明）、时间、操作（最多两个小按钮，卡片处理一次点按时灰掉）。急事和标准的「今天」一样叠：同一个应用同一类的 3 件以上叠成一行（「8 封可疑邮件」，后面写第一件的副标题加「等」），点「展开」一行一件列出来；最多 3 行，其余收在「还有 N 件急事」。要你决定的一行一件，次序和标准的「今天」一样（同一类的挨着）。卡片里有要填、要选的（选项、输入框、日期、滑条、勾选），这一行不给按钮，给「选一下」，在下面展开成标准的卡片。打开网页的按钮，网站写在按钮后面；没写网站的不列。

**活动**：时间线。时间在左、右对齐；一条竖线上的点，急事红、刚做的用强调色；应用图标、做了什么、撤销或放回。按今天、昨天分组。beta 2 不画这一页。

**应用的页**：每个应用一页，上面是工具出的基础页（`service.pages`，A2UI），应用要用户做的事都在这一页里做，窗口不打开工具自己的界面（`service.ui`，11-09 定）。有新版本时在页上能升级。

**添加应用**：列出螺壳挑好、签过名的全部应用，装之前看得到会做什么、要什么权限、占多大。装、升级、换回、卸载归主控。

**设置**：五个标签。

| 标签 | 放什么 |
|---|---|
| 提醒 | 主动提醒总开关；简报（默认每天早上，能选早晚各一次、只在我打开时）和通知里那一句的样子；免打扰（默认 22:00–08:00）；每类事怎么说（当场说、放进简报、只放在窗口里、不要） |
| 显示 | 「今天」的密度：标准（卡片）或紧凑（一张表），带小样；只记在这台 Mac 的这个窗口里 |
| 权限 | 系统权限（列在螺壳或应用名下，写明谁在用）、账号、代你做的事、每次都问的事 |
| 模型 | 档位和模型、引擎状态、能耗、用电池时也在后台跑 |
| 隐私 | 数据只在这台 Mac 上、记忆、诊断信息、卸载螺壳 |

**搜索和问螺壳**：同一条输入条，在窗口底部，⌘K 或直接打字叫出。

- 打字就出搜索结果，不经模型，各来源先回先画；「搜索结果」进整页，按来源分段、能筛。
- 回车让螺壳回答。回答浮在当前页上，带上下文标签（在哪一页、选中了哪一行），Esc 收起；会改动东西的按钮照样要点。
- 一问一答不留痕迹；想留的「钉到今天」，想接着聊的「展开」成整页对话（记录在「活动」里）。
- ⌥Space 在任何窗口里叫出同一个面板；在工具自己的窗口里，工具把选中的东西递过来（`service.ui.context`，当数据）。

## 顶部菜单：完整入口

螺壳在前台时，屏幕顶部的菜单就是完整入口；侧栏收起来也一步就到。菜单只放入口，不写计数和状态。

| 菜单 | 项 |
|---|---|
| 螺壳 | 关于螺壳；设置…（⌘,）；检查更新…；隐藏、隐藏其他、全部显示；退出螺壳（⌘Q） |
| 编辑 | 系统标准的几项 |
| 显示 | 收起侧栏 / 展开侧栏（⌃⌘S）；进入全屏幕 |
| 前往 | 今天（⌘1）、活动（⌘2）、搜索或问螺壳（⌘K）；应用：每个装好的应用、添加应用…；权限、模型 |
| 窗口 | 系统标准的几项 |
| 帮助 | 螺壳使用说明 |

「前往」里的应用列表和侧栏的一样，来自装好的应用。

## 菜单栏图标：只放必要的

别的程序在前台时，螺壳只在菜单栏留一个图标。

- 平时不带数字；有急事（「当场说」的那几类）没处理时多一个小点，处理完就没了。关了「主动提醒」没有小点，暂停提醒时照旧有。
- 点开只有：状态（「螺壳在运行」；暂停时写到几点）、急事（有才列）、打开螺壳、暂停提醒一小时、退出螺壳。
- 急事同一个应用同一类的合成一行（「8 封可疑邮件」），最多 5 行。点了一行回「今天」，滚到那一叠并展开；那一叠收在「还有 N 件急事」后面时先把急事全展开（「还有 N 件急事…」那一行滚到菜单里没列出的第一叠）。
- 不列应用、活动、设置；要去这些地方，打开螺壳用侧栏或顶部菜单。

## 提醒

- 每类事四档：当场说、放进简报、只放在窗口里、不要。默认只有可疑邮件、安全问题当场说。
- 系统通知只给当场说的。简报默认每天早上一份（原来攒满一小时，见 [DESIGN.md](../DESIGN.md) §5）。
- Dock 图标不带数字。
- 有新版本在「今天 · 顺便看看」，记忆想问的在「要你决定」，等你允许的权限在「今天」的卡片和「设置 · 权限」。
- 关掉「主动提醒」：agent 不再主动发简报和通知；窗口、「今天」、基础页照旧在。

## 谁定、谁画

用户只看到一个螺壳、一个窗口；后面主控和 agent 仍是两个组件（顶层 ADR 0014 的 10-27 修订）。

| 界面的哪一块 | 谁定 | 谁画 |
|---|---|---|
| 外框、侧栏、页面布局 | 主控 | 主控 |
| 「应用」一行和展开的列表、「添加应用」；装、升级、换回、卸载；首次设置 | 主控 | 主控 |
| 顶部菜单（完整入口） | 主控 | 主控 |
| 菜单栏图标（状态、急事） | 哪件算急事由 agent 说，照「设置 · 提醒」里当场说的那几类 | 主控 |
| 「今天」里主控自己的行（有新版本、装好了） | 主控 | 主控 |
| 搜索结果页 | 各工具回结果（`service.ask.search`），agent 汇总 | 主控 |
| 「今天」：出哪些事、什么顺序、什么时候出 | agent | 主控 |
| 卡片 | 工具写内容（A2UI，放 outbox），agent 校验、挑时机 | 主控 |
| 工具的基础页 | 工具写（`page/<id>`） | 主控 |
| 深界面（扫描的文件夹树、规则编辑） | 工具 | 工具自己的 .app |
| 邮件助手、记忆现有的网页 | 各自 | 过渡期由主控用网页视图套进窗口 |

卡片和基础页由同一个渲染器（本仓库的 `LuokeA2UI`）画。

## 接口

见 [界面接口.md](界面接口.md)（草案）。

- 「今天」和卡片走 `/feed`，点按交回 `/action`。
- 「今天」的计数、菜单栏图标的小点，都从 `/feed` 的 `cards` 算。

## 样子和动效

**卡片模板**（2026-11-09）：卡片标题后面可以跟一个标签（邮箱地址）；一封一行：发件人加粗、主题一行放不下省略、截止标签（已过红、快到橙），下面一行理由；右边是选择框（1 pt 边、白底、高 28，左边是选中那项的图标、右边向下的箭头，同一张卡片里对齐成一列）和一个小按钮（加入日程：日历图标和时间，网站在悬停提示里）；卡片里分块，每块一个小标题（图标 + 字）和自己的按钮；「判为可疑」那块先收起，只写一句「206 封，都先不动」。卡片底下的按钮图标和字都画（「✓ 加星标 3」），只有一条后面的几个按钮（扫描页的「移到废纸篓」）只画图标。时间在卡片右上角，只占标题那一行。`scripts/today_template.py` 用 `cards.py` 照对照稿拼出整页，截图 `today-template`。

**图标**：窗口和卡片里的图标都是 Lucide（lucide-static 1.64.0，ISC，`window/Sources/LuokeWindow/Resources/lucide/`，用到哪个放哪个），`LKIcon("名字", size:)` 画，跟着字色；默认 16 pt，SF Symbol 原来几号字的换成大两号（Lucide 的图在 24 格里留了边）。卡片里的 `Icon` 经 `a2uiIcon` 拿窗口带的图，别的宿主（输入法）退回最接近的系统符号。菜单栏图标不在此列。

- 颜色在 `Theme.swift`。字号只用 26、15、14、13、12，字重只用常规、中等、半粗；间距在 4 pt 的格子上；圆角 6、8、14、20（「一件件处理」的面板 16）。
- 卡片：浅色是白底加一层很淡的影子（`0 1 2` 6 %、`0 4 12 -6` 10 %，#3A1F14），没有边；深色是 1 px 的边（白的 6 %），没有影子。
- 按钮四级：实心的主按钮、浅底的次按钮（字色的 6 %，没有边）、只有字的、浅红底红字的（不好撤回的：移到垃圾邮件，没有边）。行里的「撤销」「放回」是红字的字按钮。
- 侧栏选中是字色的 7 % 的底，没有影子。
- 动效（`Motion.swift`）。曲线：进场 `(0.23,1,0.32,1)`、移动 `(0.77,0,0.175,1)`、抽屉 `(0.32,0.72,0,1)`、退场 `(0.3,0,0.8,0.15)`。

| 动作 | 怎么动 |
|---|---|
| 按下按钮 | 90 ms 缩到 0.97 |
| 答完一件 | 卡片 130 ms 淡出、缩到 0.97；别的 320 ms 补位（进场，晚 50 ms）；应用图标 440 ms 飞进「已经替你做了」新的那一行，往左边空白处偏约 36 pt 再落回，路上从 28 缩到 20；那一行的字在图标落地时（约 280 ms）出现，每段 220 ms，错开 30 ms；计数在落地时滚一格 |
| 撤销 | 图标沿原路飞回；还在路上就从当时的位置倒回去 |
| 进「一件件处理」 | 第一张卡片 420 ms 长成面板（抽屉）；「今天」150 ms 淡出（退场）；面板里的各块从 100 ms 起错开 35 ms |
| 下一件 | 旧的 160 ms 往上走 12 pt；新的 70 ms 起 300 ms 从下面 16 pt 来；进度那一格 260 ms 填满；键盘上按的只淡入淡出 120 ms |
| 换页 | 侧栏选中的底 280 ms 滑过去（移动）；旧页 130 ms 淡出（退场）；新页各块 260 ms 升 8 pt，错开 30 ms；「活动」的竖线 420 ms 从上往下画出来 |
| 点开简报 | 下面的内容 340 ms 让位；那段话 170 ms 起 420 ms 升 10 pt |
| 密度的分段 | 240 ms 滑过去 |

减少动态效果时只淡入淡出，不超过 150 ms，按钮按下不缩。

## 实现（`window/`）

Swift 包 `LuokeWindow`（macOS 14 起），螺壳.app 引它；卡片和基础页用同仓库的 `LuokeA2UI` 画。

- `MainWindowView(model:)`：整个窗口；`LuokeCommands`：顶部菜单（换掉「显示」里的侧栏一项，加「前往」）；`StatusMenuContent`：菜单栏图标的菜单。三处都从 `WindowModel` 读，顶部菜单和菜单栏图标的项来自同一份描述（`topMenus`、`statusMenu`）。
- 接 agent 核心：`AgentConnection(socketPath:model:)` 订阅 `agent.sock` 的 `/feed`，「今天」的四段、菜单栏图标的急事、「设置 · 提醒」用核心的（`AgentFeed` 把事件填进 `WindowModel`）；点按和改设置经 `WindowBackend` 交回 `/action`、`/settings`。螺壳.app 报窗口和在不在用 `reportWindow`、`reportPresence`，系统通知照 `feed.onNotify` 发。不接时（截图、测试、`luoke-window-demo` 不带 `--agent`）用示例数据（`Sample`，和原型一样）。「接上核心」的截图和测试里，螺壳扫描那部分是它的场景样例经真核心得来的（`ToolSample`，`Resources/samples/`，由 `scripts/window_samples.py` 生成，见工具协议 §11），邮件助手、记忆的还是手写的。
- 应用的页（接口 §6）：接上核心时照 `GET /apps` 画：运行状态和概览一句话、页的标签（只画 `pages`，同一个编号只画一次；`ui.pages` 不画成标签，也不再有「打开完整界面」（11-09 定，替掉 11-08 的做法））、缺的权限（`needs`，点了进「设置 · 权限」）；每一页是工具的 A2UI，打开、换标签、`apps` 事件、页上点完按钮时重新取，按钮照卡片走 `/action`。窗口不调 `POST /open`（接口留着）。核心没连着的应用（例如记忆）照旧。
- 「设置 · 权限」（§10）：打开时取 `GET /permissions`；在螺壳名下的（`owner: "luoke"`）同一项合成一行，写哪些应用在用。按钮只照每行的 `can` 出（`settings`「打开系统设置」、`request`「允许」→ 先出说明、点「继续」才交、`on`/`off` 是开关、`open`「打开」、`remove`「移除」），点了才调 `POST /permissions`，答的那句话画成底部的提示；每次都问的只列出来。在螺壳名下的系统权限接着本体时点了调 `WindowHost.askPermission`，下面每个应用一行「允许」的开关（§10）。
- 螺壳自己的权限：螺壳.app 自己查（例如完全磁盘访问），启动时和变了时调 `WindowModel.reportHostPermissions(["fda": .granted])`（或 `AgentConnection.reportHost(permissions:)`），转成 `POST /host`；值是 `.granted`、`.denied`、`.ask`，`nil` 是不再报这一项。连接记着报过的，核心重启、重新连上时再报一遍。窗口不查系统的授权。
- 窗口里的按钮、开关、分段、下拉框都自己画（样子照原型，颜色在 `Theme.swift`）；`LuokeA2UI` 加了可选的样式接口（`a2uiButtonStyle`、`a2uiDrawn`、`a2uiCardChrome`、`a2uiFont`），窗口把卡片画成同一个样子，不设的宿主照旧是系统样式。
- 简报：点了核心发的通知，本体调 `model.openNotification(userInfo)`：编号是 `brief` 的回「今天」并把简报放在最上面（`openBrief()`），别的回「今天」。`收起` 是 `closeBrief()`。
- 一件件处理：`enterFocus()`（`enterFocus(category:)` 只走一类，类见 `decideCategories`、`categoriesToPick`）、`skipFocus(viaKey:)`、`answerFocus(_:viaKey:)`、`answerFocusPrimary()`、`exitFocus()`；答了的是用户在这里点过、已经从「要你决定」里走掉的；工具把卡片换掉时（同一类，`TodayStack.key`，又出了一张新的），新的顶在原来的位置（正看着的还是这一件），工具收走的从这一轮里去掉，都不算答了；同一个应用别的类的新卡片不算换上来的，只走一类时这一轮里不混进别的类。换掉还是收走照 `feed` 判断：核心先删旧卡片、再发新的、最后发 `feed`，删掉的那张画到 `feed` 到了为止（`AgentFeed`），中间不会少一张。
- 密度：`setDensity(.compact)`，记在 `UserDefaults`（`luoke.window.density`）。
- 截图：`Snapshot.screens()` 列出全部界面（146 个，各有浅色、深色）。默认照螺壳.app 现在发的样子画：beta 2 精简版（`.beta2`：今天、应用页、设置，底部只有搜索）、接上核心、侧栏「应用」展开；邮件助手和螺壳扫描的卡片、页、权限都是它们录的场景样例经真核心得来的（`ToolSample`，默认邮件 `suspicious`、扫描 `full-report`：一张很长的一轮卡片），不手写。另有：`-whole` 是整页（窗口拉高，往下滚才看得到的也画出来）；`stress-` 是压力场景（录的卡片复制几份、什么都没有、还在等、页面拿不到、最小和大窗口、宽窗口）；`full-` 是完整版里 beta 2 还没有的页（活动、问螺壳、对话、记忆……），用手写的 `Sample`。要看自己这台 Mac 上真实的样子：`scripts/window_this_mac.py` 照 agent 的读请求录下本机邮件助手和螺壳扫描现在的答复（只读，用数据的拷贝，不连在跑的那份），再用 `LUOKE_WINDOW_SAMPLES`、`LUOKE_WINDOW_SCENARIO=this-mac` 截图；里面是真邮件和真路径，只在本机看，不进仓库、不放画廊。`luoke-window-shots <目录>` 画成 PNG。离屏画、不开窗口，没有图形会话也能跑。每个 PR 由 GitHub Actions 截一遍，贴在 PR 的评论里，和 main 比变了哪些界面。
- 接螺壳.app（本体，luoke-core#68）：本体实现 `WindowHost`，设到 `WindowModel.host`。模型、隐私、添加应用、升级交给它，打开本体现有的窗口。菜单栏用本体的菜单，`StatusMenuItems.items(model:openWindow:)` 给急事、打开螺壳、暂停提醒那几项现成的 `NSMenuItem`。系统设置由窗口打开（`AgentConnection.settingsOpener`）。beta 2 只画今天、应用页、「设置 · 提醒」「设置 · 权限」：本体设 `model.features = .beta2`。见 [界面接口.md](界面接口.md) §14。
- 演示：`swift run --package-path window luoke-window-demo` 用示例数据开一个窗口（要在有图形界面的 Mac 上）。
- 测试：`swift test --package-path window`。界面行为照原型的自查一条条对过来（侧栏、图标列、「应用」一行、卡片点按和撤销、一件件处理、简报、密度、权限、问螺壳、设置、顶部菜单、菜单栏图标），样子和动效的值有自己的测试（`ThemeTests`）；截图测试检查每个界面都画得出、不是空白、没有画不出的系统控件，同一个界面画两次一样。
